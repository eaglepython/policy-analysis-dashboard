# 📊 Policy Analysis Dashboard

An interactive web-based platform for exploring data-driven policy insights using AI governance metrics, healthcare savings analysis, and regulatory trade-off modeling.

## 🚀 Features
- 📈 AI Vendor Market Share — HHI metric + antitrust alerts
- 🏥 Healthcare Cost Analysis — AI-driven savings over time
- ⚖️ Policy Impact Modeling — Innovation vs. safety trade-offs
- 📤 Upload your own CSV files
- 🐍 Download Python analysis scripts
